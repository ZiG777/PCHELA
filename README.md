# PCHELA

Telegram-магазин на Python и SQLite. Покупатель пополняет внутренний баланс, выбирает категорию, товар и количество, затем подтверждает списание. Номер и статус заказа доступны в разделе «Мои заказы». Навигация магазина и админ-панели находится в нижней клавиатуре Telegram. Счёт открывается кнопкой «Оплатить» под сообщением о пополнении.

## Запуск

Для установки нужен Python 3.12 или новее. Команды выполняются из корня репозитория.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp -n .env.example .env
```

Заполните `.env` или задайте переменные в настройках хостинга.

| Переменная | Значение |
| --- | --- |
| `BOT_TOKEN` | Токен бота от @BotFather |
| `ADMIN_IDS` | Числовые Telegram ID администраторов через запятую |
| `ADMIN_URL` | Ссылка на администратора, которую увидит покупатель без username |
| `SUPPORT_URL` | Ссылка на поддержку, доступная также по команде `/paysupport` |
| `REFERRAL_PERCENT` | Процент от каждого подтверждённого пополнения приглашённого пользователя, по умолчанию 5 |
| `DATABASE_PATH` | Файл SQLite, по умолчанию `data/shop.sqlite3` |
| `SHOP_CURRENCY` | `XTR` для Telegram Stars или `USDT` для CryptoBot и xRocket |

```bash
.venv/bin/python -m shop
```

Бот работает через long polling. Запускайте один экземпляр на токен. Храните SQLite на постоянном диске и делайте резервные копии базы. Для запуска нужен доступ к `api.telegram.org`.

## Настройка каталога и выдача

1. Каждый администратор открывает чат с ботом и отправляет `/start`, чтобы получать уведомления.
2. В нижнем меню администратор открывает «Админ-панель» и добавляет категории и товары. Категории можно переименовать через «Редактировать категорию». Название, описание и цену товара можно изменить через «Редактировать товар».
3. После списания с баланса бот присылает покупателю номер заказа, а администраторам отправляет уведомление с номером и ссылкой на покупателя. Если у покупателя нет username, покупатель получает ссылку на администратора и просьбу сообщить номер заказа.
4. После ручной выдачи администратор открывает «Заказы к выдаче», выбирает заказ и нажимает «Выдано». Бот уведомляет покупателя.

В «Кабинете» видны Telegram ID, текущий баланс, сумма подтверждённых пополнений за всё время и статистика заказов. Оттуда открывается реферальная программа. После каждого подтверждённого пополнения приглашённого пользователя пригласивший получает процент от суммы на отдельный реферальный баланс. Бонус округляется вниз до целой звезды или до цента USDT. При создании заявки на вывод сумма резервируется. Администратор самостоятельно согласует способ выплаты и выполняет перевод, затем нажимает «Выплата выполнена». При отклонении сумма сразу возвращается на реферальный баланс.

## Платежи

Для магазина цифровых товаров внутри Telegram используйте `SHOP_CURRENCY=XTR`. Это режим по умолчанию. Суммы в нём указываются целыми Stars. [Правила Telegram для цифровых товаров](https://core.telegram.org/bots/payments-stars).

Для сценариев, где разрешена внешняя оплата, доступны CryptoBot и xRocket. Установите `SHOP_CURRENCY=USDT` и заполните `CRYPTOBOT_TOKEN` и `XROCKET_TOKEN`. В меню появятся провайдеры с заданными токенами. Для CryptoBot можно использовать тестовую среду, задав `CRYPTOBOT_TESTNET=true` и тестовый токен. Нужен исходящий доступ к `pay.crypt.bot` (или `testnet-pay.crypt.bot`) и `pay.xrocket.tg` для соответствующих провайдеров. Подтверждение счетов происходит автоматически через опрос API. Валюта фиксируется в базе при первом запуске. Для другого режима укажите отдельный файл базы.

## Проверка

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Тесты используют локальную базу и имитируют ответы Telegram, CryptoBot и xRocket. Для проверки реальных платежей нужны реквизиты провайдеров и сетевой доступ.
